Tabelle anlegen (einmalig im Supabase-Dashboard unter SQL Editor) 

    
    
Die Policy „Voller Zugriff“ erlaubt jedem mit dem Key Lesen, Schreiben und Löschen der Tabelle projekte. Für den Produktivbetrieb Supabase Auth einrichten und auf to authenticated einschränken.

  

  

    Tabellen für die Personalplanung anlegen (einmalig im SQL Editor)
    

    
    
Legt mitarbeiter, einsatz_codes und einsaetze an. Danach in der Ansicht „Personal“ die Excel-Planung importieren. Auch hier gilt die offene Policy „Voller Zugriff“.

  

  

    Zugriff nur mit Login (Schritt 3 – vor dem Veröffentlichen ausführen)
    

    
    
Ersetzt die offene Policy „Voller Zugriff“ durch „Nur angemeldet“. Danach sehen und ändern nur Nutzer mit Login die Daten. Nutzer legst du in Supabase unter Authentication → Users → Add user an („Auto Confirm User“ anhaken). Unter Authentication → Sign In / Providers „Allow new users to sign up“ ausschalten.
